# LioSnack26
Lio Snack - Sistema de Gestión e Ecommerce
Este proyecto consiste en el desarrollo de un sistema web integral diseñado para Lio Snack, un emprendimiento salvadoreño dedicado a la producción y venta de snacks de frutas naturales. El sistema busca modernizar la operación del negocio, sustituyendo el manejo manual en Excel por una plataforma que integra control de inventarios, administración de ventas y una tienda en línea.

Descripción del Proyecto
Lio Snack actualmente opera con limitaciones en el control de su stock y visibilidad digital. Esta solución propone: 
Tienda en Línea: Un canal digital para que los clientes finales exploren el catálogo y realicen pedidos.
Panel Administrativo: Herramienta interna para que los socios gestionen la producción, distribución, marketing y finanzas. 
Control de Inventario: Monitoreo exacto de materia prima (fruta) y producto terminado.  

Funcionalidades Principales 
Niveles de Usuario   Administrador: Acceso total. Gestión de inventarios, configuración de precios, reportes financieros y emisión de documentos fiscales (Crédito Fiscal). 
Producción: Actualización de stock de materia prima y registro de lotes fabricados.  
Distribución: Visualización de puntos de venta externos y rutas de entrega.  
Marketing: Gestión de contenido visual de la tienda y promociones de la marca.  
Cliente Final: Navegación del catálogo, carrito de compras y seguimiento de pedidos.
